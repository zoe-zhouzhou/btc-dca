FAQ
常见问题
如何更新或重新生成导入码？
导入码不会过期。如果想更新策略，重新填写问卷 → 进入策略页 → 点击「安装 Skill」即可生成新码。问卷评分保存在浏览器中，无需全部重填。
Skill 会收集我的资金信息吗？
不会。导入码仅包含画像类型和策略参数，预算金额始终只保存在你的本地，从不上传至任何服务器。
如何更新策略配置？
重新填写问卷 → 进入策略页 → 点击「安装 Skill」生成新码 → 在 Skill 对话中说「更新策略，新导入码是 [粘贴你的完整导入码]」即可覆盖原有配置。
本地数据存在哪里？
所有配置和执行记录存储在 ~/.btc-dca/ 目录下（config.json、local.json、strategy.json、execution-log.json），删除该目录即可完全卸载。
