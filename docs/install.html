01
选择运行平台
OpenClaw 是 AI 原生平台，Skill 通过对话完成安装，每日信号检测结果直接推送到你的聊天频道，无需额外配置。
Claude Code 为本地 CLI 方案。每日检测通过系统 crontab 运行 Node 脚本，推送需配置 Telegram Bot Token。
02
安装步骤 · OpenClaw
1
安装 Skill
一行命令下载 Skill 并安装依赖，无需克隆整个仓库：
npx degit zoe-zhouzhou/btc-dca/btc-dca-skill ~/skills/btc-dca-skill && npm install --prefix ~/skills/btc-dca-skill
2
启动 Skill 对话
Skill 检测到未初始化，会自动引导你完成安装：设置预算、配置推送渠道、建立每日定时检测。
openclaw chat --skill ~/skills/btc-dca-skill/SKILL.md
3
Skill 自动设置每日定时推送
安装完成后，Skill 会调用 openclaw cron add 注册每日 08:00 的自动任务。每天早报必达：周期评分、价格、子弹剩余；触发定投条件时在早报后追加买入提醒。
02
安装步骤 · Claude Code
1
安装 Skill
一行命令下载 Skill 并安装依赖：
npx degit zoe-zhouzhou/btc-dca/btc-dca-skill ~/.claude/skills/btc-dca-skill && npm install --prefix ~/.claude/skills/btc-dca-skill
2
启动 Skill 对话
在 Claude Code 中输入以下斜杠命令，Skill 检测到未初始化后会自动引导你完成配置：输入导入码、设置预算、配置 Telegram Bot。
/btc-dca-skill
3
（可选）配置 Telegram 推送
在 @BotFather 创建 Bot，获取 Token 和 Chat ID，安装流程中会引导你完成。
也可以跳过，信号提醒将在 Claude Code 对话内展示。
4
Skill 自动注册系统 crontab
安装完成后，Skill 会调用 crontab 注册每日 08:00 的自动任务。每天通过 Telegram 发送早报（周期评分、价格、子弹剩余）；触发定投条件时在同一条消息内追加买入提醒。

FAQ
常见问题
导入码过期了怎么办？
导入码有效期 7 天。过期后返回策略页，重新点击「安装 Skill」即可生成新码。问卷评分仍保存在浏览器中，无需重新填写。
Skill 会收集我的资金信息吗？
不会。导入码仅包含画像类型和策略参数，预算金额始终只保存在你的本地，从不上传至任何服务器。
如何更新策略配置？
重新填写问卷 → 进入策略页 → 点击「安装 Skill」生成新码 → 在 Skill 对话中说「更新策略，新导入码是 XXXXXX」即可覆盖原有配置。
本地数据存在哪里？
所有配置和执行记录存储在 ~/.btc-dca/ 目录下（config.json、local.json、strategy.json、execution-log.json），删除该目录即可完全卸载。
