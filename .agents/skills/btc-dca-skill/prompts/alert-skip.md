# 跳过提醒模板

## 单次跳过确认

```
好的，这次跳过已记录。

下次触发时我会再提醒你。
如果是因为手头紧张或资金安排变化，可以告诉我，
我们可以调整策略参数或暂停提醒一段时间。
```

---

## 连续跳过 3 次提醒

```
【策略执行提醒】

你已经连续跳过了 {{skip_count}} 次触发信号：
  第 1 次：{{skip_1_date}}（{{skip_1_type}}，已过 {{skip_1_days}} 天）
  第 2 次：{{skip_2_date}}（{{skip_2_type}}，已过 {{skip_2_days}} 天）
  第 3 次：{{skip_3_date}}（{{skip_3_type}}，已过 {{skip_3_days}} 天）

连续跳过可能意味着策略和你的实际情况不再匹配。

你可以：
  回复【评估策略】：重新回答几道关键问题，调整策略
  回复【继续执行】：保持当前策略，我继续提醒
  回复【暂停提醒】：暂停 30 天（30 天后我会再问你一次）
```

---

## 暂停确认

```
好的，我会在 {{resume_date}} 之前暂停提醒。

如果你想提前恢复，直接告诉我「恢复提醒」就好。

市场信号检测仍在后台运行，
恢复提醒后你会立刻收到最新的信号状态。
```
